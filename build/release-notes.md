Windows 10/11 x64 무설치 버전입니다. ZIP 압축을 모두 풀고 Capture Program.exe를 실행하세요.

- 실행 취소 왼쪽에 이미지 자르기 버튼을 추가했습니다.
- 1:1, 3:4, 4:3, 9:16, 자유형 비율을 지원합니다.
- 지정 크기 캡처처럼 영역 이동, 모서리·테두리 크기 조절, Shift/Alt와 방향키 조절을 지원합니다.
- Enter/적용으로 자르고 Esc/취소로 되돌립니다. 자르기도 실행 취소와 원본 복원을 지원합니다.
- 핀 고정한 이미지의 자르기 결과를 재실행 후에도 유지합니다.

Windows에서 실제 ZIP 실행, 비율별 자르기, 영역 조절, 실행 취소와 보관을 검증했습니다.
