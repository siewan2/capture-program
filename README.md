# Capture Program

Windows 10/11용 화면 캡처 및 간단한 이미지 편집 데스크톱 앱입니다.

## 실행

Node.js 22 이상을 설치한 Windows에서:

```powershell
npm ci
npm start
```

설치 파일 생성:

```powershell
npm run dist
```

`dist` 폴더에 NSIS 설치 파일이 생성됩니다. 서명 인증서는 포함하지 않았습니다.

## 사용법

- **영역 선택**: 모니터 선택 창 없이 앱이 숨겨지고 모든 모니터 위에 선택 화면이 표시됩니다. 원하는 화면에서 마우스로 드래그한 뒤 놓으면 즉시 캡처됩니다. 역방향 드래그와 화면 배율을 지원합니다. `Esc` 또는 마우스 오른쪽 버튼으로 취소합니다.
- **창 캡처**: 별도의 창 목록 없이 현재 화면에서 마우스 아래의 창을 빨간색 블록·테두리로 표시합니다. 원하는 창을 클릭하면 해당 창 전체를 캡처합니다. 겹친 창은 앞에 있는 창을 우선 선택합니다. Windows 네이티브 창 좌표를 사용하며 최소화되거나 보호된 창은 캡처되지 않을 수 있습니다.
- **지정 크기 캡처**: 프리셋을 선택하고 화면 위에서 원하는 좌상단 위치를 클릭하면 즉시 캡처됩니다. 화면 경계에서는 위치를 안쪽으로 조정합니다. 크기는 원본 픽셀 기준이며 모니터보다 큰 프리셋은 사용할 수 없습니다.
- **프리셋**: 설정 탭에서 여러 너비·높이를 추가/삭제하고 캡처 탭에서 선택합니다. 프리셋과 선택한 크기는 다음 실행에도 유지됩니다.
- **캡처 목록**: 캡처 직후 왼쪽에 표시됩니다. 각 항목은 독립적으로 편집하며, 항목 아래 **이 이미지 저장** 버튼으로 해당 이미지만 저장합니다. **모두 저장** 버튼으로 목록 전체를 저장할 수 있습니다. 선택하지 않은 이미지도 자신의 편집 결과로 저장됩니다.
- **편집**: 펜, 형광펜, 텍스트, 사각형, 원, 시계 방향 90° 회전, 최근 20단계 실행 취소를 지원합니다. 편집은 이미지에 합쳐지며 적용 후 개별 도형·텍스트를 선택하는 레이어 편집은 지원하지 않습니다.
- **형광펜**: 노랑·초록·하늘·분홍·주황·보라 등의 빠른 색상 또는 원하는 색을 고릅니다. 두께는 1~100px, 불투명도는 10~80%로 조절합니다. 한 번의 획에서는 선분이 겹치는 부분의 투명도가 누적되지 않습니다.
- **도형**: 사각형·원을 선택한 뒤 색상과 선 두께(1~100px)를 설정합니다. 도구마다 색상·두께를 따로 유지합니다(현재 실행 동안).
- **실시간 텍스트**: 텍스트 도구를 고르면 이미지 위 커서가 I 모양으로 바뀝니다. 이미지를 클릭하고 직접 입력합니다. 입력 상자 테두리·배경 없이 글자와 커서만 표시됩니다. 입력 중 도구 모음의 색상과 글자 크기(8~240px)를 바꾸면 이미지에 즉시 미리보기가 반영됩니다. Enter로 줄바꿈하고 **텍스트 적용** 또는 Ctrl+Enter로 확정합니다. **취소** 또는 Esc로 되돌립니다. 이미지 전환·저장·회전·다른 도구 선택 시 입력 중인 텍스트는 자동 적용됩니다.
- **클립보드**: 캡처 목록에서 이미지를 선택하고 Ctrl+C를 누르면 편집 결과가 이미지로 복사됩니다. 그림판이나 메신저에서 Ctrl+V로 붙여넣으세요. 텍스트 입력란에 포커스가 있으면 일반적인 텍스트 복사를 유지합니다.
- **영역 선택 돋보기**: 커서 옆에 5배 확대 화면과 십자선을 표시해 모서리 위치를 확인합니다. 설정에서 켜고 끌 수 있으며 선택 상태가 유지됩니다.
- **저장**: 설정 탭에서 PNG 또는 JPEG(.jpg)를 선택합니다. JPEG는 품질 92%로 변환하며 투명한 부분은 흰색으로 채웁니다. 기본 저장 형식은 다음 실행에도 유지됩니다. 설정의 **저장 폴더 → 폴더 선택**에서 저장 경로를 지정합니다. 기본 위치는 Windows 사진 폴더 아래 `Capture Program`이며 폴더 설정도 다음 실행에 유지됩니다. 저장 버튼을 누르면 파일 선택 창 없이 지정 폴더에 고유한 이름으로 저장하고 기존 파일을 덮어쓰지 않습니다. 모두 저장 중 일부 파일이 실패하면 나머지는 계속 저장하고 성공·실패 개수를 표시합니다. 선택한 형식은 저장할 때 적용되며 편집 중에는 무손실 이미지를 유지합니다. 캡처 목록과 편집 이력은 메모리에만 보관되며 종료하면 지워집니다.

영역·지정 크기 캡처는 각 모니터 전체를 덮는 테두리 없는 선택 화면을 사용합니다. 캡처 시작 시점의 화면을 정지시킨 상태에서 선택하며, 한 번의 영역 선택은 드래그를 시작한 모니터 안으로 제한됩니다. 화면 연결이나 배율이 바뀌면 진행 중인 캡처를 취소합니다. 창 이미지는 Electron의 창 스냅샷을 사용하며 최대 7680 × 4320 경계 내의 해상도입니다. 자동 저장, 트레이 기능은 포함하지 않습니다.

## 설정과 단축키

상단 **설정** 탭에서 저장 형식·폴더, 영역 선택 돋보기, 전역 캡처 단축키, 지정 크기 프리셋을 설정합니다. 설정은 자동 저장됩니다. 기본 단축키는 영역 선택 `Ctrl+Shift+1`, 창 캡처 `Ctrl+Shift+2`, 지정 크기 `Ctrl+Shift+3`입니다. 단축키 입력란을 클릭하고 Ctrl/Alt와 문자·숫자 조합 또는 F1~F24를 누르세요. Backspace/Delete로 해당 단축키를 해제합니다. 중복이나 OS 등록 실패는 입력란 아래 표시됩니다. 전역 단축키는 앱 실행 중에만 유효하며, 캡처 선택 대화상자가 열려 있으면 새 캡처 요청을 무시합니다. 다른 앱과의 단축키 충돌 및 실제 Windows 전역 단축키·클립보드·창 선택 동작은 Windows에서 확인해야 합니다.

## 검증

```powershell
npm test
```

영역 좌표 정규화, Windows 네이티브 창 열거(Windows에서 실행), 창 겹침 순서·좌표 변환, 다중 모니터 선택 화면 관리·취소, 화면 배율 변환, 화면 경계 제한, 프리셋 입력 검증, 단축키 등록 결과 처리, PNG/JPEG 파일 저장·동시 저장 시 파일명 중복 방지·저장 경로 오류를 테스트합니다. 실제 Windows에서는 다중 모니터/배율, 창 캡처, PNG 저장 및 설치 파일 실행을 확인해야 합니다. Linux의 헤드리스 검증은 Windows 캡처 기능의 검증을 대체하지 않습니다.

## GitHub에서 Windows 빌드 다운로드

저장소의 **Actions → Build Windows app**에서 성공한 실행을 선택한 뒤, 하단 **Artifacts → Capture-Program-Windows-x64**를 다운로드합니다(GitHub 로그인 필요). ZIP 압축을 모두 풀고 `Capture Program.exe`를 실행하세요. 설치나 Node.js는 필요 없습니다. 아티팩트 보관 기간은 14일입니다.

`main`에 코드를 올리면 자동 빌드합니다. 다시 빌드하려면 Actions의 **Run workflow**를 사용하세요. 서명되지 않은 테스트 버전이며 실제 Windows 캡처 동작은 직접 확인해야 합니다.
