# Capture Program

Windows 10/11용 화면 캡처 및 간단한 이미지 편집 데스크톱 앱입니다.

## 실행

Node.js 22 이상을 설치한 Windows에서:

```powershell
npm ci
npm start
```

Windows 설치 파일 생성:

```powershell
npm run dist
```

`dist` 폴더에 `Capture-Program-Setup-버전.exe` 설치 파일이 생성됩니다. 설치 마법사에서 경로를 고르고 설치하면 시작 메뉴와 바탕화면 바로가기가 생성됩니다. 설치 후 설정에서 Windows 자동 실행을 켜세요. 기존 무설치 버전은 자동 실행을 끄고 트레이에서 완전히 종료한 뒤 설치하세요. 고정 이미지와 도구 설정은 같은 사용자 앱 데이터 폴더에 유지됩니다. 서명 인증서는 포함하지 않았습니다.

## 사용법

상단 로고·저장 헤더와 기본 메뉴바를 제거해 이미지 편집 영역을 넓혔습니다. 저장은 캡처 목록의 우클릭 메뉴에서 합니다.

- **영역 선택**: 모니터 선택 창 없이 앱이 숨겨지고 모든 모니터 위에 선택 화면이 표시됩니다. 화면 전체에 커서를 따라 움직이는 얇은 빨간 십자선을 표시합니다(돋보기 설정과 무관). 원하는 화면에서 마우스로 드래그한 뒤 놓으면 즉시 캡처됩니다. 역방향 드래그와 화면 배율을 지원합니다. `Esc` 또는 마우스 오른쪽 버튼으로 취소합니다.
- **창 캡처**: 별도의 창 목록 없이 현재 화면에서 마우스 아래의 창을 빨간색 테두리만 표시합니다. 창 내용에는 색상이나 음영을 덧씌우지 않습니다. 원하는 창을 클릭하면 해당 창 전체를 캡처합니다. 겹친 창은 앞에 있는 창을 우선 선택합니다. Windows 네이티브 창 좌표를 사용하며 최소화되거나 보호된 창은 캡처되지 않을 수 있습니다.
- **지정 크기 캡처**: 전체 모니터를 합친 선택 화면 하나에서 마지막으로 캡처를 완료한 크기의 선택 상자 하나가 마우스 근처에 나타납니다. 처음 사용하는 경우 선택한 프리셋 크기로 시작합니다. 마지막 크기는 앱을 재실행해도 유지하며, 취소한 크기나 영역·창 캡처 크기로 덮어쓰지 않습니다. 선택 화면에서 프리셋을 고르거나 크기를 바꿔 캡처하면 다음 지정 크기 캡처부터 그 크기를 사용합니다. 상자를 드래그해 다른 모니터로 옮기거나 모니터 경계에 걸쳐 캡처할 수 있습니다. 내부를 드래그해 이동하고 네 모서리·상하좌우 8개 조절점이나 테두리를 드래그해 크기를 바꿉니다. Shift를 누른 채 조절하면 시작 비율을 유지하고, Alt를 누르면 중심을 고정해 양쪽을 동시에 조절합니다. 두 키를 함께 사용할 수 있습니다. 방향키는 원본 픽셀 기준 1px씩 이동하고 Shift+방향키는 10px씩 이동합니다. Enter, 더블클릭 또는 캡처 버튼으로 확정하고 Esc로 취소합니다. 전체 모니터를 합친 화면 경계 밖으로 넘어가지 않으며 그보다 큰 프리셋은 화면 안에 맞춰 축소해 시작합니다. 모니터 배치 사이의 빈 영역은 검정색으로 캡처됩니다. 선택 화면의 프리셋 목록에서 크기를 바꾸거나 가로·세로 픽셀 수치를 입력하고 적용할 수 있습니다. 입력란의 Enter는 크기만 적용합니다. 프리셋 추가 버튼으로 현재 크기를 저장하면 메인 창과 설정에도 반영됩니다. 기존 프리셋은 변경하지 않습니다.
- **프리셋**: 설정 탭에서 여러 너비·높이를 추가/삭제하고 캡처 탭에서 선택합니다. 프리셋과 선택한 크기는 다음 실행에도 유지됩니다.
- **캡처 목록**: 캡처 직후 왼쪽에 표시됩니다. 각 항목은 독립적으로 편집합니다. 썸네일 왼쪽 위의 배경 없는 핀 아이콘으로 고정하면 원본과 편집 결과를 앱 데이터 폴더에 보관하고 재실행·재부팅 후에도 복원합니다. 핀 해제 시 현재 목록에는 남지만 다음 실행에는 복원하지 않습니다. 오른쪽 위 X로 삭제하면 고정 보관본도 삭제합니다. 고정 이미지의 편집 내용은 자동 저장하며 실행 취소 이력은 재시작 시 초기화됩니다. 메인 캡처 화면에서 위·아래 방향키로 이전·다음 이미지를 선택합니다. 선택한 썸네일이 보이도록 목록을 자동 스크롤하며 처음·마지막에서 멈춥니다. 텍스트·숫자·선택 상자 입력 중에는 해당 입력의 방향키 동작을 유지합니다. 이미지를 우클릭하면 **이미지 저장…**과 **삭제** 메뉴가 나타납니다. 이미지 저장은 파일 이름과 경로를 매번 선택합니다. **모두 저장** 버튼으로 PNG/JPEG 형식을 고른 다음 저장 폴더를 선택해 목록 전체를 저장합니다. 선택하지 않은 이미지도 자신의 편집 결과로 저장됩니다.
- **보기 확대·축소**: 메인 이미지 또는 주변 여백에서 **Ctrl+마우스 휠**을 위로 돌리면 확대, 아래로 돌리면 축소합니다. Ctrl을 누르고 오른쪽·위로 드래그하면 확대, 왼쪽·아래로 드래그하면 축소합니다. 스크롤로 확대된 이미지를 살펴볼 수 있습니다. 보기 배율만 바뀌며 저장 해상도와 편집 이력에는 영향을 주지 않습니다. 각 이미지의 보기 배율은 현재 실행 동안 유지됩니다.
- **편집**: 시작할 때 형광펜이 기본 선택됩니다. 펜·형광펜·지우개 두께, 형광펜 불투명도, 도형 채우기·색상·두께, 텍스트 크기·색상·굵게·기울임·밑줄 설정은 자동 저장되어 다음 실행에도 유지됩니다. 펜, 형광펜, 텍스트, 사각형, 원, 자유형 도형·선, 지우개, 왼쪽·오른쪽 90° 회전, 원래대로, 최근 20단계 실행 취소를 지원합니다. 편집은 이미지에 합쳐지며 적용 후 개별 도형·텍스트를 선택하는 레이어 편집은 지원하지 않습니다.
- **형광펜**: 노랑·초록·하늘·분홍·주황·보라 등의 빠른 색상 또는 원하는 색을 고릅니다. 두께는 1~100px, 불투명도는 10~80%로 조절합니다. 한 번의 획에서는 선분이 겹치는 부분의 투명도가 누적되지 않습니다.
- **도형**: 사각형·원을 선택한 뒤 선 색상과 두께(1~100px), 테두리만/채우기만/채우기+테두리, 별도의 채우기 색상을 주요 색상 팔레트에서 선택합니다. 도구마다 색상·두께를 따로 유지하며 프로그램 종료·재부팅 후에도 복원합니다.
- **지우개**: 브러시를 드래그해 추가한 메모를 지웁니다. 흰색으로 덮지 않고 해당 위치의 원본 화면을 복원하며, 회전한 이미지에서도 올바른 원본 위치를 사용합니다. 지우개 크기를 조절할 수 있고 한 번의 획은 실행 취소할 수 있습니다.
- **원래대로**: 캡처한 최초 이미지와 방향으로 돌아갑니다. 원래대로도 실행 취소할 수 있습니다.
- **자유형: 도형**: 클릭으로 꼭짓점을 추가하고 드래그로 자유곡선 구간을 그립니다. 닫힌 도형/열린 선을 선택할 수 있고 닫힌 도형은 채우기도 지원합니다. 더블클릭, Enter, 완료 버튼 또는 시작점 클릭(닫힌 도형)으로 완성합니다. Esc/취소로 되돌리고 Backspace로 마지막 점을 제거합니다. 완성한 자유형은 한 번의 실행 취소로 지웁니다.
- **실시간 텍스트**: 텍스트 도구를 고르면 이미지 위 커서가 I 모양으로 바뀝니다. 이미지를 클릭한 직후 바로 타이핑할 수 있습니다. 입력 중에는 글자 길이에 맞춰 늘어나는 작은 임시 네모 테두리가 표시되고 바로 위에 크기·색상·굵게(B)·기울임(I)·밑줄(U) 도구막대가 뜹니다. 색상 버튼을 누르면 검정·흰색·회색·빨강·주황·노랑·초록·파랑·보라·분홍 팔레트에서 바로 선택할 수 있습니다. 색상 선택 후에도 입력란으로 포커스가 돌아와 타이핑을 계속할 수 있습니다. 입력 중 색상·글자 크기(8~240px)·굵게·기울임·밑줄을 바꾸면 이미지에 즉시 미리보기가 반영됩니다. 첫 클릭으로 입력을 시작하고 이미지나 입력 상자를 다시 클릭하면 입력을 마칩니다. Enter로 줄바꿈하고 **텍스트 적용** 또는 Ctrl+Enter로도 확정할 수 있습니다. 입력 완료 시 임시 테두리와 도구막대가 사라지며 저장 이미지에도 포함되지 않습니다. **취소** 또는 Esc로 되돌립니다. 이미지 전환·저장·회전·다른 도구 선택 시 입력 중인 텍스트는 자동 적용됩니다.
- **클립보드**: 영역·창·지정 크기 캡처가 완료되면 이미지가 자동 복사됩니다. 캡처 취소 시 기존 클립보드를 유지합니다. 복사에 실패해도 캡처 목록에는 이미지가 남고 오류를 표시합니다. 캡처 목록에서 이미지를 선택하고 Ctrl+C를 누르면 편집 결과가 이미지로 복사됩니다. 그림판이나 메신저에서 Ctrl+V로 붙여넣으세요. 텍스트 입력란에 포커스가 있으면 일반적인 텍스트 복사를 유지합니다.
- **영역 선택 돋보기**: 커서 옆에 2배 확대 화면과 십자선을 표시해 모서리 위치를 확인합니다. 설정에서 켜고 끌 수 있으며 선택 상태가 유지됩니다.
- **저장**: 설정 탭에서 PNG 또는 JPEG(.jpg)를 선택합니다. JPEG는 품질 92%로 변환하며 투명한 부분은 흰색으로 채웁니다. 기본 저장 형식은 다음 실행에도 유지됩니다. 개별 저장 시 파일 저장 대화상자를 매번 표시하며, 파일 형식 목록에서 PNG/JPEG를 고를 수 있습니다. 설정의 기본 형식이 목록의 첫 항목이 되며, 최종 파일 확장자(.png/.jpg/.jpeg)에 맞는 데이터로 저장합니다. JPEG를 선택했다가 PNG로 저장하더라도 원본 PNG에서 저장해 불필요한 손실 변환을 피합니다. 모두 저장 시에는 PNG/JPEG 형식과 폴더를 매번 선택하고 고유한 파일명으로 저장해 기존 파일을 덮어쓰지 않습니다. 모두 저장 중 일부 파일이 실패하면 나머지는 계속 저장하고 성공·실패 개수를 표시합니다. 선택한 형식은 저장할 때 적용되며 편집 중에는 무손실 이미지를 유지합니다. 고정하지 않은 캡처와 편집 이력은 메모리에 보관되며 트레이에 숨겨도 유지되지만 앱을 완전히 종료하면 지워집니다. 핀 고정한 캡처는 앱 데이터 폴더에 보관해 다음 실행에도 유지합니다.

영역 캡처는 각 모니터 전체를 덮는 테두리 없는 선택 화면을 사용하며, 지정 크기 캡처는 전체 모니터를 덮는 창 하나를 사용합니다. 캡처 시작 시점의 화면을 정지시킨 상태에서 선택합니다. 선택 화면은 기본적으로 음영 없이 표시하고 빨간 십자선·선택 테두리로 영역을 확인합니다. 설정의 **캡처 화면 음영**을 켜면 영역·지정 크기 선택 영역 바깥을 어둡게 표시합니다. 음영은 별도 화면 요소로 처리하므로 배경 이미지를 매번 다시 그리지 않습니다. 배경 이미지는 한 번 표시하고 마우스 이동 시 가이드만 갱신합니다. 백그라운드 캡처는 고정 대기 없이 시작하며, 편집 창이 보이는 경우에만 숨긴 뒤 40ms 기다립니다. 다중 모니터 선택 창은 동시에 불러옵니다. 한 번의 영역 선택은 드래그를 시작한 모니터 안으로 제한됩니다. 화면 연결이나 배율이 바뀌면 진행 중인 캡처를 취소합니다. 창 이미지는 Electron의 창 스냅샷을 사용하며 최대 7680 × 4320 경계 내의 해상도입니다. 자동 저장은 포함하지 않습니다.

## 설정과 단축키

상단 **설정** 탭에서 밝은/어두운 배경 스타일, 저장 형식, 영역 선택 돋보기, 전역 캡처 단축키, 지정 크기 프리셋을 설정합니다. 기본 스타일은 밝은 스타일입니다. 설정은 자동 저장됩니다. 기본 단축키는 영역 선택 `Ctrl+Shift+1`, 창 캡처 `Ctrl+Shift+2`, 지정 크기 `Ctrl+Shift+3`, 캡처 목록 열기 `Ctrl+Shift+4`입니다. 캡처 목록 열기는 트레이에 숨겨진 창을 복원하며, 설정에서 키 변경·해제가 가능합니다. 단축키 입력란을 클릭하고 Ctrl/Alt와 문자·숫자 조합 또는 F1~F24를 누르세요. Backspace/Delete로 해당 단축키를 해제합니다. 중복이나 OS 등록 실패는 입력란 아래 표시됩니다. 전역 단축키는 앱 실행 중에만 유효하며, 캡처 선택 대화상자가 열려 있으면 새 캡처 요청을 무시합니다. 다른 앱과의 단축키 충돌 및 실제 Windows 전역 단축키·클립보드·창 선택 동작은 Windows에서 확인해야 합니다.

## 백그라운드 실행

닫기(X)를 누르면 종료하지 않고 트레이에 숨겨집니다. 숨겨진 상태에서도 캡처 단축키는 작동하며, 캡처를 마치면 편집 창이 다시 나타납니다. 트레이 아이콘을 더블클릭하거나 우클릭 메뉴의 **프로그램 열기**를 누르면 창을 복원합니다. 트레이 메뉴에서도 캡처를 시작할 수 있습니다. **완전히 종료**를 선택하면 앱과 단축키가 종료됩니다.

새 버전을 실행하기 전에는 기존 버전을 트레이에서 완전히 종료하세요. 중복 실행 시 기존 창을 다시 엽니다. 설정의 **Windows 시작 시 자동 실행**을 켜면 다음 Windows 로그인부터 메인 창 없이 트레이에서 시작하고 캡처 단축키를 사용할 수 있습니다. 기본값은 꺼짐이며 끄면 Windows 시작 등록을 해제합니다. 실행 파일을 보관할 폴더에 압축을 푼 뒤 설정하세요. 경로를 옮기거나 새 버전으로 교체하면 새 실행 파일에서 다시 켜야 합니다. Windows 작업 관리자에서 시작 앱을 차단한 경우 해당 설정도 확인하세요. 개발 모드와 Windows 이외 환경에서는 이 옵션을 사용할 수 없습니다.

## GitHub에서 Windows 빌드 다운로드

저장소의 **Actions → Build Windows app**에서 성공한 실행을 선택한 뒤, 하단 **Artifacts → Capture-Program-Windows-Installer-x64**를 다운로드합니다(GitHub 로그인 필요). GitHub Actions는 다운로드를 ZIP으로 감싸서 제공하므로, 안의 `Capture-Program-Setup-버전.exe`를 실행해 설치하세요. 앱 실행에 Node.js는 필요 없습니다. 아티팩트 보관 기간은 14일입니다.

`main`에 코드를 올리면 자동 빌드합니다. 다시 빌드하려면 Actions의 **Run workflow**를 사용하세요. 서명되지 않은 테스트 버전이며 실제 Windows 캡처 동작은 직접 확인해야 합니다.
