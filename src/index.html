Windows 시작 시 자동 실행

메인 창 없이 트레이에서 시작하며 캡처 단축키를 바로 사용할 수 있습니다. 이 옵션을 켜면 Windows에 자동 실행을 등록합니다. 실행 파일을 보관할 폴더에 압축을 푼 뒤 켜주세요. 위치를 옮겼다면 새 앱에서 다시 켜주세요.

설정

변경 사항은 자동 저장됩니다.

배경 스타일

선택한 스타일은 다음 실행에도 유지됩니다.

백그라운드 실행

닫기(X)를 누르면 트레이로 숨겨지고 캡처 단축키는 계속 작동합니다. 트레이 아이콘을 더블클릭하거나 캡처 목록 열기 단축키(기본 Ctrl+Shift+V)로 창을 다시 열 수 있습니다. 완전히 종료하려면 트레이 메뉴의 ‘완전히 종료’를 선택하세요.

저장 이미지 형식

JPEG 품질은 92%이며, 투명한 부분은 흰색으로 저장됩니다. 개별 저장 시 파일 경로를, 모두 저장 시 폴더를 매번 선택합니다.

캡처 이미지 자동 테두리

이미지 안쪽에 적용하여 가로·세로 크기를 유지합니다. 저장과 클립보드 복사에도 포함됩니다. 설정 변경은 이후 새 캡처부터 적용합니다.

캡처 화면 음영

영역 선택·지정 크기 캡처에 적용됩니다. 기본값은 꺼짐이며, 설정은 다음 실행에도 유지됩니다.

영역 선택 돋보기

선택 모서리 주변을 확대해 정확한 위치를 확인합니다.

캡처·목록 단축키

앱이 실행 중이면 다른 프로그램을 사용하면서도 캡처할 수 있습니다. 입력란을 선택하고 원하는 키 조합을 누르세요. Backspace 또는 Delete로 해제합니다.

지정 크기 프리셋

너비와 높이는 원본 화면 픽셀 기준입니다. 캡처 탭에서 사용할 크기를 선택하세요.
